# Changelog

All notable changes to this documentation site will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Entries are not written here by hand: each change adds a fragment under
[`changelog/unreleased/`](changelog/unreleased/README.md), and the fragments are assembled into a
dated section with `pwsh ./scripts/changelog.ps1 assemble`.
